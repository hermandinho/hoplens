# @hoplens/cli

Command-line tool for [Hoplens](https://hoplens.dev). Installs as `hoplens` on your `PATH`.

```bash
npx hoplens init     # wire Hoplens into next.config and instrumentation
npx hoplens doctor   # check that everything is in place (Phase 5)
npx hoplens remove   # unwire (Phase 5)
```
